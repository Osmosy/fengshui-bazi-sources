# fengshui-bazi — первоисточники по бацзы и фэншуй

Навык для агента: навигация по 16 классическим текстам китайских искусств судьбы (≈2 300 страниц)
с постраничными ссылками на сканы Source Library. Не пересказ «в общем», а карта источников:
что в какой книге, на какой странице, каким методом считается.

**Языки:** русский (изложение), китайский (термины и цитаты), английский (переводы XIX века).

## Состав

```
SKILL.md        навык: как пользоваться, карта знаний, индекс глав, таблица источников
chapters/       по одной сводке на книгу или блок книг (10 файлов)
glossary.md     термины всех книг: иероглиф → определение → книга/страница
patterns.md     пошаговые процедуры: 排八字, 病藥, 河洛求数, 八宅-план, 擇日, 太乙運式, 龜卜
cheatsheet.md   таблицы: 干支/五行, 十神, 十二長生, 三合六合三刑, 空亡, 神煞, 八宅, 九宮
```

## Как пользоваться

1. Определить тему → открыть главу из индекса в `SKILL.md`.
2. Цитировать с номером страницы (маркеры `--- Page N ---` в полных текстах) и ссылкой
   `https://sourcelibrary.org/book/<slug>`.
3. Если в сводке нет — искать в полных текстах: `grep -r "термин" ~/books/source-library/zh/<slug>/`.

## Ограничения

- Викторианские синоло­ги (de Groot, Edkins) описывают традицию извне, с оценками
  «superstition»; в главах это помечено отдельно — позиция автора не равна содержанию традиции.
- OCR-ловушки исходников: 巳/己, 戍/戌, служебные символы в английских файлах;
  при цитировании иероглифов сверять контекст.
- Не для современных гадательных услуг и не вне китайской традиции.
