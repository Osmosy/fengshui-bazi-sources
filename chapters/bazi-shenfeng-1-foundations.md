## Методы и процедуры
- **安身命宮** (установка дворцов Жизни/Тела): 命宮 ставится по часу 卯 (восток, дерево, «человеколюбие» = долголетие), 身宮 — по часу 酉 (запад, металл, «должное» = завершение тела). Оценка по звёздам в 命宮; если пусто — смотреть 三合宮 (напр. 寅→午戌), затем 四正宮. — стр.7-8
- **安星辰法** (расстановка звёзд): 五星指南 = 體 (основа), 琴堂殿駕 = 用 (применение). Дворцы: 寅亥=木, 卯戌=火, 辰酉=金, 申巳=水, 子丑=土, 午=太陽, 未=太陰; взаимодействия по 生剋; всё судить по 命宮, не по 身宮 («命在身先»). — стр.8
- **論度主** (хозяин градуса): элемент градуса, где стоит 命宮; планета-помощник градуса = 恩星, планета-разрушитель = 難星. Конфликт «дворец любит / градус ненавидит» решается в пользу 命宮. — стр.9
- **看命下手處** (стартовый порядок разбора): сначала 日干, затем 月令; элемент 月令 берём «пучком» — сверяем, повторяется ли в 年/月/時; скрытые стволы прочих ветвей пока не смотреть, иначе «混雜不明» — «從重者論». — стр.21-22
- **動靜說**: стволы (天干) = «движение» (陽), ветви (地支) = «покой» (陰); ствол поражает только ствол (в карте и в 运), ветвь — только ветвь; strike через скрытые стволы невозможен. — стр.16-17
- **庫/冲**: 辰戌丑未 — склады, «заперты»; содержимое (напр. 戊乙癸 в 辰) освобождается только встречной ветвью (辰需戌冲, 丑需未冲) → «襍氣財官，喜見冲». — стр.17
- **蓋頭說**: ствол над ветвью («голова») решает; в 大運 ствол «покрывает» ветвь: если 病神-ствол сверху — ветвь не действует; наоборот — скрытая 病 под «лечебным» стволом безвредна. «看八字以此蓋頭字望見了就識得人一生好反，此是真傳秘訣». — стр.17-18
- **病藥說**: 病 = вредящая звезда в карте; 藥 = элемент, удаляющий её. Иерархия: 病重得藥 = 大富大貴; 病輕得藥 = 略富略貴; 無病無藥 = 平常人. Балансировать через 大運. — стр.20-22
- **四病 雕枯旺弱**: 雕 — «неогранённая» чистая карта без соперников (требует «резьбы»); 枯 — 財官有根 но без сезона (ждать 旺運; 无根之枯 = 弊); 旺 — избыток элемента (лечить countered luck); 弱 — слабость (ценна при наличии 根; 弱極無根 = страх). — стр.22-24
- **損益生長** (четыре лекарства): 損 — reduce избыток (官旺→傷官運 и т.д.); 益 — подпитать недостаток (木弱→水運); 生 — 陽干生處真生 (甲生亥), 陰干生處 = 弱 (乙生午), 陰干死處反為生 (乙死亥), 陽干死處真死 (甲死午); 長 — 帝旺之鄉 (木在寅卯辰), отличается от 長生: здесь喜剋 не喜生. — стр.24-25
- **正官格**: 陽見陰/陰見陽; 月上官星 «нельзя использовать» (он лишь управляет) → годен только при 1 очке при сильном 日主 (身強官輕 → 貴, 喜官旺運); ослабшего官 nourish 財, избыточный — 制食神;官印雙全無刑冲破害 = 廊廟材 (乙生申月, 丁生亥月, 巳生寅月, 辛癸生巳月). — стр.25-27
- **偏官格/七殺**: 陽見陽/陰見陰; принцип «有殺先論殺，無殺方論用»; цель — 制伏 (食神/傷官) в меру: «盡法無民» при переборе, «奴反主» при недоборе. Сильный при слабом殺 — используй殺 как власть. — стр.31-32
- **棄命從殺格**: 日主全無生氣, 四柱純官殺 → follow 殺; нужно 財生殺, идти 財殺運; бояться 根 и 制殺運. Только 六陰日干 имеют «право следовать»; 六陽日 при 殺多 = 殺重身輕 (если совсем без 氣 — тоже 從). — стр.32
- **時上一位貴格**: одна 七殺 в часе, 日主旺, звезда не повторяется в 年月日; ствол «透出» лучше; требуется 制伏 (или 合去) — тогда 偏官, иначе 七殺; 制過 2-3 раза = 寒儒. Месячный殺 боится刑冲, часовой — нет (喜刃冲). — стр.52-56
- **官殺去留**: при смеси убрать одно, оставить другое (去官留殺/去殺留官); в стволах легко убрать, скрытые в 月支 — трудно; средства — 傷官/食神 (их «много и сильно» нужно). Скрытое правило стихов: 官殺相連只論殺; 露殺藏官只論殺, 露官藏殺只論官. — стр.56-59
- **貪合忘殺/忘官**: 闲神 combine-ом устраняет星: 凶神合去反為吉, 吉神合去反為凶; примеры: 癸见己(殺)+甲合己; 壬见己(官)+甲合己; 壬遇戊(殺)得癸合救. — стр.57-58
- **月支正財格**: 財=養命之物; 身旺能任; 身弱財多 = «盜賊偷人財物». 身旺比劫多喜官殺去比劫; 財旺身弱喜比劫分/印運助; 偏財 > 正財 (陰尅陰陽尅陽 «有氣»); «逢財喜殺而遇殺，十有九貴». — стр.61-63
- **棄命從財格**: любой 日主 без силы идёт за 財; надо 生起財星; бояться 身旺 и 印地; «北行入格，南走為灾» (丁酉月例) — против догмы «從財忌殺». — стр.62-64
- **時上偏財格**: 偏財 в часе (甲見戊辰時, 庚見甲/寅時), только 1 шт., без 沖破 (寅冲申, 酉冲卯), без 敗財/羊刃; 身旺任財喜食神運; 身旺比劫多喜官殺; 偏財喜官星, 正財忌官星. — стр.67-68
- **傷官格**: 真傷官 (родной сезон, напр. 甲乙生巳午未月 — предельно опасно 泄) vs 假傷官 (甲乙生正二月見火 — «虛火», любит官旺 и 伤官运). Правила по столбам: 年帶傷官父母不全, 月帶傷官兄弟不完, 時帶傷官子息凶頑, 日帶傷官妻妾不免. — стр.70-75
- **傷官十論** (по каждому стволу 1 куплет: 甲木傷官寅午全…癸水傷官怕見官) — построчные рецепты удач/бед по направлениям 大運. — стр.76-77
- **食神格**: 我生同陽同陰 (甲見丙); 天廚食神 (丙祿在巳/丁祿在午 при встрече); «食神有氣勝財官»; 1 шт. = 貴神, повтор = 傷官; тело должно быть 旺; 最大的忌 — 梟神奪食 (лечится 偏財). — стр.72, 76
- **印綬格**: 正印/偏印; 月逢印綬喜官星 (官印相生), 忌財鄉 (貪財壞印) — но «死格»: 印太旺身旺必用財破印; 印多身弱畏財. 真印 (丙丁生寅卯) vs 假印 (丙生亥月用甲木 — 需東方運); 印綬若多，財要見也 (水泛木浮 → 土運止水). — стр.92-96
- **陽刃格**: только 六陽日干; 甲刃=卯(乙):刃旺無益 = 病, 用庚合去或酉冲; 刃為用神時 (身弱) 反畏酉运冲刃; «殺無刃不顯，刃無殺不威», 刃殺停均 = 兵刑顯宦. — стр.99-100
- **建祿格**: 月令=日主祿地 (甲生寅月), 財官死絕於此 → «月令建祿多無祖屋», 等待財官旺運. — стр.100
- **Проверка по «корню»**: «根在苗先» — если в карте нет ни капли 金氣, то даже 金運 не удержит殺 (карта нищего). — стр.47

## Ключевые термины (для глоссария)
- 日干/日主 (Day Master) — ствол дня, «сам»; «日為身主» — стр.2, 13
- 月令 (Month Command) — «巢穴», главный элемент месяца; «月為巣穴，歳與時為門戶» — стр.2, 21
- 用神 (Useful God) — элемент, которым пользуются после устранения болезней — стр.2, 26
- 大運 (Great Cycles) — десятилетние периоды; 小運 — годовые — стр.3, 5
- 正官/偏官 (Direct/Indirect Officer) — 陽見陰/陰見陰; 偏官=七殺 — стр.25, 31
- 七殺 (Seven Killings) — 7-й по счёту ствол от 日干 («殺身之刀劍») — стр.31
- 正財/偏財 — заработанное/«чужое» богатство; 偏財=衆人之財 — стр.61, 67-68
- 傷官 (Hurting Officer) — «伤杀其官，不服官管»; 巧而傲 — стр.70
- 食神 (Eating God) — 我生同 polarity; «盜我血氣» мягче — стр.70, 76
- 正印/偏印/梟神 (Seal/Owl) — 生我者; 偏印 при наличии 食神 = 梟神 — стр.92-95
- 比肩/劫財 (Peer/Rob Wealth) — 同我者; 分奪財神 — стр.11, 61
- 陽刃 (Yang Blade) — пиковая энергия 六陽日干 (甲刃在卯) — стр.99-100
- 建祿 (Established Lu) — 日主 в собственной祿地月令 — стр.100
- 根 (root) — скрытая опора в ветвях; «弱而有根» обязательно — стр.24, 47
- 蓋頭 (Covering the Head) — ствол, «накрывающий» ветвь — стр.17-18
- 庫 (Storehouse) — 辰戌丑未, открываются только 冲 — стр.17
- 三合 (Triple Harmony) — напр. 寅午戌, 巳酉丑, 亥卯未 — стр.8, 38, 75
- 空亡 (Void, 六甲空亡) — 甲子旬中戌亥空; 財落空亡必貧窘 — стр.63
- 官殺混雜 (mixing Officer & Killings) — «當壽夭» без 去/留 — стр.33, 39
- 貪合忘殺/忘官 — комбинация снимает殺/官 — стр.57-58
- 梟神奪食 (Owl seizes Food) — 偏印破食神 → 不貧則夭 — стр.72, 76
- 貪財壞印 (greed destroys Seal) — 財星破印 — стр.93, 95
- 水泛木浮 (water floats wood) — 印盛無制 → 漂蕩 — стр.95-96
- 有病方為貴 — девиз школы 病藥 — стр.20
- 命宮/身宮 (Life/Body Palace) — 卯/酉 установки — стр.7
- 恩星/難星 (Grace/Adversity stars) — планеты-помощники/вредители градуса — стр.8-9
- 七曜/四餘 (Seven Luminaries / Four Remnants: 羅計氣孛) — 七曜禍淺, 四餘禍烈 («狐假虎威») — стр.9
- 納音 (NaYin) — «海中金» пары лет; автор считает основой 謬說 — стр.9-12
- 進氣 (advancing energy) — элемент входит в силу (乙生寅 «進氣之木») — стр.81, 90

## Правила/критерии/классификации
- 五行 счёт «天一生水地二生火»: 水1 火2 木3 金4 土5; альтернативная 納音 («海中爐中») объявлена无理 — стр.9
- Дворцовые элементы: 寅亥木 卯戌火 辰酉金 申巳水 子丑土 午太陽 未太陰 — стр.8
- Шесть родственных позиций: 年=祖宗(財官榮顯, 坐比劫=飄零), 月=父母兄弟(月令官殺=損兄弟/閧墻), 偏財=父, 正印=母, 官殺=子(男)/夫(女), 傷官食神=子星(女)/損子(男) — стр.18-19
- 女: 夫星=官殺, 子星=食傷; 先看夫星, 子星次之; 無夫星別尋他格 — стр.12
- 孤鸞日 опровергнуты: 乙巳/丁巳 (内有庚/庚財生夫), 辛亥 (坐正財生夫) — 旺夫旺子; 戊申 (庚剋夫), 甲寅 (夫星絕於寅) — 真剋夫 — стр.19-20
- 十二長生 (для 甲): 長生亥, 沐浴子, 冠帶丑, 臨官寅, 帝旺卯, 衰辰, 病巳, 死午, 墓未, 絕申, 胎酉, 養戌; 陽順陰逆 — стр.75
- 陰陽長生 правило: 六陽生處真為生, 六陰生處俱為弱, 六陰死處反為生, 六陽死處真為死 (乙生午弱, 乙死亥有壬滋; 甲死午) — стр.24
- 正官月支例: 六甲日生酉月, 六乙生申巳月, 六丙生子月, 六丁生亥月 = 月正官, 無沖刑破害始為奇 — стр.26
- 官印兩全例: 乙生申, 丁生亥, 巳生寅, 辛癸生巳 — стр.26
- 純殺有制 (一品之尊) историч. карты: 岳總領 癸卯丁巳壬寅甲辰; 趙侍郎 丙午丙申甲寅丁卯; 劉八門司 甲申乙亥丙戌庚寅; 周伯蘊 戊戌甲子丁未庚戌; 毛价川 甲寅庚子丁巳戊辰 — стр.33
- 官殺去留 историч.: 帖木丞相 戊申辛酉乙巳丙子; 黃狀元 壬子甲辰己卯壬申; 脫脫太師 甲寅己巳癸酉丁巳; 史衛王彌遠 甲申丙寅乙卯辛巳; 鄭尚書 庚寅壬午戊寅甲寅 — стр.33-34
- 女命改運判斷 (夫): 身旺夫弱喜夫旺運/財運生夫, 大畏食傷運; 身弱夫重 (2-3殺) = 賤夫, 喜食傷制; 身弱無根官殺多 = 從夫 (殺旺運吉, 畏見根) — стр.12-13
- 時上偏官喜忌: 喜身強、食神先殺後 (食居先殺居後功名兩全)、羊刃冲; 忌官混 (有兄不顯其弟)、財生殺黨、身弱 — стр.53-55
- 時殺根: 丙(殺庚用)生寅旺巳午庫戌; 格解以財為根 — 亦可 — стр.55
- 傷官四局 песня: 火土傷官宜傷盡; 金水傷官喜見官; 木火傷官官要旺; 土金官去反成官; 惟有水木傷官格, 財官兩見始為歡 (水木: 見財宜, 見官不宜) — стр.74
- 傷官真假: 真傷官 = 本氣旺月泄重 (甲乙巳午未) → 喜北方水破; 假傷官 = 春木虛火 → 喜伤官运/官旺 (木火通明佐廟廊) — стр.73
- 食神制殺逢梟: 不貧則夭; 梟神 лечение — 偏財 (偏財能益壽延年, 以其能制梟) — стр.38, 76
- 印綬月例: 甲乙生亥子, 丙丁生寅卯, 戊己生巳午, 壬癸生申酉, 庚辛生辰戌丑未 (或巳午) = 月逢印綬 — стр.93

## Anti-patterns / предостережения
- **吕才合婚**: подбор пары только по 年命 (上/中/下婚) — «滅蠻經»-подобная ложь; правильный метод — мужу с 比劫重 брать жену с 傷官食神重 (и наоборот) — стр.10-11, 14
- **八敗/桃花殺** как главные табу женщин: «亥未戌生人見三月» не связано ни с 夫子星, ни с 中和; примеры благополучных женщин «с 八敗» → отбросить; настоящая причина бед — 偏枯八字 — стр.12
- **Зодиакальные ярлыки** (龍奔天河, 龍歸大海): один год-живот ничего не решает; пример 譚二華 庚辰甲申丁未丙午 — истинно «身強殺淺假殺為權» — стр.10
- **Детские 凶殺** (雷公, 金鎖, 斷橋, 百日, 雞飛; «哭斷腸不過三歲死»): устрашение родителей одним годовым иероглифом — «實謬說» — стр.10
- **進財退財/望門守寡/金輿祿忌舅姑**: только по 納音 года и месяцу,丢下日時 — ложь — стр.11-12
- **日貴格/日貴, 六乙鼠貴**: 天乙貴人 названия «飘空而立，不根理出» — стр.15
- **日德格** (甲寅戊辰丙辰庚辰壬戌), **魁罡格** (壬辰庚戌庚辰戊戌), **六壬趨艮/六甲趨乾**: «無中生有»/«天體至圓本無門戶» — 謬說 — стр.15-16
- **勾陳得位/玄武當權**: красиво лишь при сильном 戊己/壬癸; при 財多身弱/殺重身輕 — absurd — стр.16
- **從革格/潤下格**: «吾見多矣，未曾有富貴者»; 炎上 (火全巳午未) тоже не показал красоты; лишь 曲直/稼穡 реально дают 富貴 — стр.16
- **制伏太過**: одна 七殺 с 2-3 壓制 → «盡法無民», даже учёный остаётся 寒儒; одно及制 — лечится 殺旺運 — стр.32, 53, 55
- **傷官無財**: «雖巧必貧» (元理賦); 傷官+比劫無財 = 奸巧剋妻傷子之命 — стр.74
- **假傷官行印運必死, 真傷官行傷官運必滅**; 破了傷官損壽元 — стр.71, 73
- **食神獨一點被梟破**: 殺來剋身 → 壽夭貧寒 — стр.72
- **印綬畏財鄉 — не догма**: 印旺必喜財 (в противном случае 木浮); «格解謂印綬畏入財鄉之句不可拘泥» — стр.93, 96
- **貪財壞印**: 身弱用印而財來破印 → 百端之禍; пример 方武十 (凌遲死刑) — стр.93, 98
- **水泛木浮**: 甲坐子/乙生亥 с избытком 水印 → 漂蕩好酒無成; надо 土運止水 — стр.95-96
- **旺弱論命乃愚術**: судить только по силе/слабости — «十無一二有驗»; надо 病藥 + 動靜歸秀氣 («十有八九驗») — стр.20-22, 78, 81
- **刃旺反病**: 身旺不用刃 (弟分祖財), 刃為用而官殺沖刃 → 極凶殺傷 — стр.100
- **陽刃倒戈** → «必作無頭之鬼» (夏桂州/夏言 казнён 1548) — стр.100
